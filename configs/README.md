# Sanitized Configurations

Store only reviewed, non-secret excerpts or synthetic examples here. Real restorable exports belong in an encrypted location outside Git.

For each artifact record device alias/model, software release, capture date, purpose, related lab/change, sanitization performed, and whether it is an excerpt, synthetic example, or checksum/reference to an external backup. Never commit credentials, keys, community strings, public addresses, serials, or full raw exports.
